# 🌱 Agri-Sensing Hub & Diagnostic Terminal

An advanced agronomic intelligence platform designed to empower smallholder farmers with automated digital crop certificates and decentralized trade passports. The system evaluates live multi-spectral satellite imagery metrics, runs autonomous AI diagnostics, and anchors crop verification records onto a secure cloud document database with scannable dynamic routing profiles.

🚀 **Developed for the Google Cloud Rapid Agent Hackathon (June 2026)**

---

## ⚡ Core Features

* **🛰️ Satellite Telemetry Integration:** Simulates real-time multi-spectral sensor mapping (NDVI Crop Health Indices) to verify field vegetative vigor profiles objectively.
* **🤖 Autonomous Gemini Agronomic Agent:** Leverages the advanced `gemini-2.5-flash` model via the next-generation Google GenAI SDK to synthesize specialized regional diagnostic logs and optimization yields.
* **🎖️ Digital Agri-Trade Passports:** Generates cryptographically safe ledger reference records stored directly on a remote MongoDB Atlas document database cluster.
* **📱 Dynamic Two-Page Verification System:** Utilizes a native matrix-layer QR engine to output scan paths routing instantly to a live isolated verification gateway (`/verify?cert_id=...`) for third-party marketplace auditing.
* **📄 High-Fidelity Asset Engines:** Compiles programmatic, tamper-proof downloadable commercial certificates using the ReportLab document layout registry.

---

## 🛠️ Architecture & Tech Stack

* **Frontend Interface:** Streamlit (Dynamic multipage configuration routing)
* **AI Orchestration Engine:** Google GenAI SDK (`gemini-2.5-flash`)
* **Database Infrastructure:** MongoDB Atlas Cloud (Mongoose Node Mapping Cluster)
* **Asset Blueprint Generators:** ReportLab PDF Engine & PyQRCode/Pillow Matrix Pipeline
